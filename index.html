Gianluca's Deck Probability Calculator

Find exact odds for cards and combos in a hand drawn without replacement. Created for Yugioh retro formats, usable with any card game.

1 · Deck and hand

Each drawn UG draws one more card; if that card is also UG, it draws again. UG is not a combo card or jolly. Results refer to cards seen after all UG draws resolve.

2 · Cards

Each card name must be unique. Unlisted cards count as other cards in the deck.

3 · Combos

Enter the minimum copies of each card needed together. Add identified jolly types and select every required card each may replace. Each drawn jolly replaces one missing card, even if it has several possible targets. Jolly copies are physical cards counted separately in the deck.
